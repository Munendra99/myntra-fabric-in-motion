# 👗 Myntra Fabric in Motion — Interactive Wishlist MVP

> **Next-Generation Mobile-Web Fashion Experience Driving Wishlist-to-Purchase Conversion with Zero Monetary Incentives**  
> *Built with React 18, TypeScript, Tailwind CSS, Vite, and Lucide Icons.*

---

## 🌟 Overview & Problem Solved

Fashion e-commerce platforms suffer from massive cart and wishlist abandonment due to two primary customer frictions:
1. **Fabric Drape & Texture Ambiguity:** Static photos fail to communicate weight, transparency, fall, and authentic motion of delicate ethnic wear and structured silhouettes.
2. **Size & Fit Doubts:** Customers hesitate, postpone purchases, and treat wishlists as passive moodboards.

**Myntra Fabric in Motion** eliminates this hesitation through dynamic, tactile discovery without relying on margin-eroding discount incentives:
- **Instant Drape & Motion Video:** Authentic 360° motion clips demonstrating fabric fall, zari sheen, and runway movement.
- **PDP Auto-Gliding Carousel:** Seamless photo-to-video auto-transition on the Product Detail Page (1.8s delay with smooth playback).
- **Tactile Fabric Specifications:** Clear transparency, weave type, GSM, and tactile feel indicators.
- **Myntra Mobile-First Polish:** Native-feeling delivery address header, category pills, responsive desktop/mobile toggle, and wishlist management.

## 🛠️ Technology Stack

- **Framework:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started Locally

### 1. Prerequisites
- **Node.js**: v18.0.0 or later
- **npm**: v9.0.0 or later

### 2. Installation
```bash
cd myntra-fabric-mvp
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be output to the `dist/` directory.

## 📱 Features & Interactions

- **Responsive View Switcher:** Toggle between **📱 Mobile (430px container)** and **💻 Desktop Fluid** mode on any screen.
- **Direct Video Modal:** Click `▶ Watch Video` directly on any wishlist card for instant modal playback.
- **Auto-Gliding Carousel:** On the Product Detail Page, view high-res 3:4 portrait photography, followed by an automatic slide into the motion video.
- **Tactile Specification Chips:** Detailed material, weave, transparency, and hand-feel metrics embedded on the PDP.
